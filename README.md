# NEON STRIKE · 霓虹突袭

赛博朋克风格网页打飞机游戏。零依赖、零构建,双击即可玩;已内置 Android 打包工程,可一键产出 APK。

**当前版本:v1.2.0**

## 快速开始

### 网页版

**在线试玩: <https://hailaij.github.io/dafeiji/>**(GitHub Pages)

- 直接双击 `index.html`(推荐 Chrome / Edge)
- 或本地服务:`python -m http.server 8080` 后访问 http://127.0.0.1:8080

### Android APK

已打包产物:**`android/dist/neon-strike-1.2.0.apk`**(≈3.1 MB)

传到安卓手机,开启「允许安装未知来源」后直接安装即可。游戏完全离线运行,无网络权限。

重新打包(游戏代码变更后,两步完成):

```powershell
# 1. 同步最新游戏资产到 android 工程
cd <仓库根>
.\sync-assets.ps1

# 2. 一键构建 APK(需先准备 JDK17 + Android SDK,详见 android/README.md)
cd android
.\build-local.ps1
```

## 难度

主菜单可选三档难度,影响敌人数值、出怪节奏、玩家命数与得分:

| 项目 | 简单 | 中等 | 困难 |
|---|---|---|---|
| 命数 | 5 | 3 | 2 |
| 敌机血量 | ×0.70 | ×1.0 | ×1.45 |
| 敌机速度 | ×0.82 | ×1.0 | ×1.22 |
| 敌弹速度 | ×0.78 | ×1.0 | ×1.30 |
| 出怪间隔 | ×1.35(更慢) | ×1.0 | ×0.78(更快) |
| 得分倍率 | ×1.0 | ×1.0 | ×1.3 |

难度作为独立倍率叠加在波次递增曲线上,三种模式全部生效;HUD 标签会实时显示当前难度。

## 玩法

- 击落敌机得分,2 秒内连续击杀触发连击倍率(最高 ×2)
- 每 5 波出现 BOSS:注意扇形弹幕,二阶段会更凶
- 道具:**W** 火力升级 / **S** 护盾(挡 3 次) / **H** 修复 HP / **B** 狂暴(6s 射速 ×2 伤害 ×1.5) / **F** 冰霜(5s 敌机敌弹减速 55%)
- **主动技能 EMP**:E 键或右下角按钮,20s 冷却,范围伤害 + 眩晕 + 清屏敌弹(肉鸽可强化)
- 暴击:肉鸽「弱点分析」可叠加,最高 30% 概率 2 倍伤害
- 最高分自动保存在浏览器本地

## 模式

- **无限模式**:波次无尽递增,追求最高分
- **闯关模式**:10 关,每关 3 波杂兵 + 1 波 Boss,通关胜利
- **肉鸽模式**:每 3 波出现三选一强化(15 种:火力/射速/伤害/散射/护盾/修复/移速/生命/得分/暴击/暴伤/磁吸/回旋护板/虹吸/EMP 强化),永久叠加直至本局结束
