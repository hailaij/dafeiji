# NEON STRIKE · 霓虹突袭

赛博朋克风格网页打飞机游戏。零依赖、零构建,双击即可玩;已内置 Android 打包工程与 Windows 桌面版(WebView2 壳),可一键产出安装包。

**当前版本:v1.6.0**

## 当前功能

- v1.6.0 新增三机型专属护盾，并修复音频挂起后 Boss 配乐无法恢复的问题。

- v1.5.1 改善鼠标与触屏跟随，快速拖动不再受固定移速上限限制。

- 新主界面与机库：游隼、壁垒、灵翼与脉冲、重弹、扇形自由搭配，实时试射九种组合，选择模式和难度后点击「开始出击」。[机型参数与验证](docs/design/hangar.md)。

- 重绘 14 种普通敌机与全部 11 种 Boss，增加蓄力、装填、相位与二阶段状态，区分护盾/治疗视觉；可打开 [美术图鉴](test/art-lab.html) 查看原始大小、灰度与碰撞圆。

- 肉鸽三条组合路线：弱点处决、电磁回路、荆棘再生，可在同一局兼容叠加。选卡展示 0/2、1/2 或激活状态，并优先提供一项未完成组合所需的强化。
- 三种入场编队：横列推进、两翼夹击、中央护航。沿用各波敌机预算，三架一组，队内紧凑、队间留出间歇；后续仍按敌机各自追踪规则行动。
- 战后结算记录主炮、EMP、反击的有效伤害，清弹数、连击、组合贡献与致命伤害来源。
- 回旋护板现在实际触发受击反击；虹吸与 EMP 的说明改为与数值一致。

新增护盾支援机与补给运输机（替换杂兵名额），移动堡垒加入可破坏的左右炮台。详细机制与测试边界见 [玩法改进说明](docs/reports/gameplay-improvements.md) 和 [敌人与炮台说明](docs/reports/enemy-expansion.md)。

## 快速开始

### 网页版

**在线试玩: <https://hailaij.github.io/dafeiji/>**(GitHub Pages)

- 直接双击 `index.html`(推荐 Chrome / Edge)
- 或本地服务:`python -m http.server 8080` 后访问 http://127.0.0.1:8080

### Android APK

已打包产物:**`android/dist/neon-strike-v1.6.0.apk`**（Android 7.0+，离线运行）。

构建 APK 后传到安卓手机,开启「允许安装未知来源」后直接安装即可。游戏完全离线运行,无网络权限。

重新打包(游戏代码变更后,两步完成):

```powershell
# 1. 同步最新游戏资产到 android 工程
cd <仓库根>
.\sync-assets.ps1

# 2. 一键构建 APK(需先准备 JDK17 + Android SDK,详见 android/README.md)
cd android
.\build-local.ps1
```

### Windows 桌面版

已打包产物:**`win/dist/neon-strike-v1.6.0-win64.exe`**(≈69 MB,Win10/11 x64)

单文件自包含,双击即玩,无需安装 .NET(仅需系统自带 WebView2 运行时);游戏资产内嵌 exe,完全离线运行。

重新打包(游戏代码变更后,两步完成):

```powershell
# 1. 同步最新游戏资产到 win 工程(同时同步 android)
cd <仓库根>
.\sync-assets.ps1

# 2. 一键构建 exe(需先准备 .NET SDK 8+,详见 win/README.md)
cd win
.\build-local.ps1
```

## 操作

| 动作 | 桌面 | 手机 |
|---|---|---|
| 移动 | WASD / 方向键 / 鼠标跟随 | 拖动屏幕(飞机在手指上方) |
| 开火 | 自动 | 自动 |
| 暂停 | P / Esc | 右上角暂停按钮 |
| 技能 | E 释放 EMP 冲击 | 右下角技能钮 |
| 开始/重开 | Enter 或点按钮 | 点按钮 |

HUD 随屏幕宽高自动换行，横屏使用紧凑布局；Boss 血条独立排列，入场高度跟随 HUD 底部。暂停图标在网页、Android 和 Windows 使用相同绘制方式。手机支持一根手指拖动飞机，同时用另一根手指按 EMP；按钮按下立即触发，无需先松开飞机。EMP 按钮用环形进度显示充能，中心显示剩余秒数，冷却结束显示「就绪」。

## 难度

主菜单可选三档难度,影响敌人数值、出怪节奏、玩家命数与得分:

| 项目 | 简单 | 中等 | 困难 |
|---|---|---|---|
| 命数 | 5 | 3 | 2 |
| 敌机血量 | ×0.65 | ×1.0 | ×1.25 |
| 敌机速度 | ×0.80 | ×1.0 | ×1.12 |
| 敌弹速度 | ×0.78 | ×1.0 | ×1.12 |
| 出怪间隔 | ×1.35(更慢) | ×1.0 | ×0.90(更快) |
| 得分倍率 | ×1.0 | ×1.0 | ×1.3 |

难度作为独立倍率叠加在波次递增曲线上,三种模式全部生效;HUD 标签会实时显示当前难度。

Boss 血量倍率分别为 0.60 / 0.75 / 1.05，预警倍率为 1.35 / 1.10 / 1.00，装填倍率为 1.65 / 1.45 / 1.00。敌弹随波次的额外增长上限为 10%，实际弹速还会叠加上表难度倍率。完整数值与复测结果见 [平衡调整报告](docs/reports/balance-adjustment.md)。

### 敌人追踪与攻击意愿

- 简单 / 中等 / 困难的追踪强度为 0.55 / 0.75 / 1.0；每隔约 0.22～0.31 秒重新感知玩家，短程预判最多横向 64 像素、纵向 40 像素。
- 杂兵、坦克和分裂母体向玩家靠拢；正弦机与织网者让蛇形中心逐步追踪。横移有加速度限制，近身或越过玩家后停止追踪。
- 枪手主动寻找射击位置，狙击手偏向侧翼，轰炸机慢速压近，镜像机快速对齐。射击高度跟随屏幕与 HUD，避免枪手漂出固定高度后不再攻击。
- 射击敌人在简单 / 中等 / 困难下分别锁定 0.55 / 0.45 / 0.40 秒再开火，红色虚线提示方向（轰炸机使用扩散环提示）；锁定后停止移动和实时瞄准，给玩家换位机会。
- 俯冲者先蓄力 0.4 秒，只在俯冲前 0.45 秒有限修正方向，随后直线冲出，速度上限 480 像素/秒，不会掉头追撞。
- 幽灵机按相位周期重新选择穿屏方向；治疗者保留后排支援定位。EMP 眩晕和冰霜减速继续作用于追踪、预警与开火计时。

### Boss 图鉴（11 种独立攻击循环）

所有 Boss 使用「锁定 → 虚线预警 → 发射 → 装填」循环；低于或等于 50% 血量进入二阶段。预警时目标坐标固定，移动可以避开锁定；EMP 可以清除已经发射的弹幕并推迟下一次攻击。

| Boss | 特性与技能 | 二阶段 | 专属战斗音乐 |
|---|---|---|---|
| 经典首领 | 交叉火网：宽扇封路与窄扇瞄准交替 | 七发扇形，每三轮召唤杂兵 | 指挥齐射 · 112 BPM |
| 蜂巢母舰 | 蜂群夹击：双侧慢速内收弹幕，召唤织网者 | 双侧五发，召唤频率提高 | 蜂巢协议 · 132 BPM |
| 幻影核心 | 相位猎杀：左右定点瞬移后锁定射击 | 五发窄扇压缩躲避空间 | 失真幽影 · 96 BPM |
| 移动堡垒 | 装甲闸门：弹墙通道左右交替；装甲受伤 ×0.6，装填受伤 ×1.5 | 弹墙提速、装填窗口缩短 | 钢铁行军 · 88 BPM |
| 风暴支配者 | 逆转风暴：三臂旋转，每臂三发 | 螺旋反转，攻击更频繁 | 电离层 · 150 BPM |
| 涅槃中枢 | 六角重构：六角阵逐轮偏转，重构期间受伤 ×1.35 | 增加错位高速外环 | 重生矩阵 · 108 BPM |
| 湮灭漩涡 | 偏心涡流：发射中心左右切换 | 八向增至十二向，换位更频繁 | 事件视界 · 126 BPM |
| 无敌重炮 | 坐标轰击：锁定玩家横坐标的三列重炮，1.15 秒预警、长装填 | 炮弹加速，装填缩短 | 攻城脉冲 · 78 BPM |
| 超新星 | 恒星脉冲：慢环与快环交替，形成追越压力 | 十二向增至十八向 | 临界燃烧 · 140 BPM |
| 双子星环 | 双核交替：左右炮口轮流瞄准 | 镜像炮口追加慢速扇形 | 镜像轨道 · 120 BPM |
| 欧米茄终局 | 终局审判：闸门、放射、瞄准三轮循环 | 放射和瞄准密度增加 | 最后指令 · 156 BPM |

音乐由 WebAudio 实时合成，包含各自的旋律、低音、鼓点和四小节和声循环；二阶段加入高音对位与切分低音。暂停、静音、Boss 死亡或退出战斗时停止，恢复后重新起奏。无需下载音频素材。

开发试听与试战：打开 `test/boss-lab.html`，选择 Boss 和阶段后点击「开始试战 / 试听」。试验场开启无敌，不改变正式游戏的难度与出场规则。详细设计见 [boss-design.md](docs/design/boss-design.md)。

## 玩法

- 击落敌机得分,2 秒内连续击杀触发连击倍率(最高 ×2)
- 每 5 波出现 BOSS:观察蓄力预警、技能循环和装填窗口
- 道具:**W** 火力升级 / **S** 护盾(挡 3 次) / **H** 修复 HP / **B** 狂暴(6s 射速 ×2 伤害 ×1.5) / **F** 冰霜(5s 敌机敌弹减速 55%)
- **主动技能 EMP**:E 键或右下角按钮,10s 冷却,范围伤害 + 眩晕 + 清屏敌弹(肉鸽可强化)
- 暴击:肉鸽「弱点分析」可叠加,最高 30% 概率 2 倍伤害
- 最高分自动保存在浏览器本地

## 模式

- **无限模式**:波次无尽递增,追求最高分
- **闯关模式**:10 关,每关 3 波杂兵 + 1 波 Boss,通关胜利
- **肉鸽模式**:每 3 波出现三选一强化(15 种:火力/射速/伤害/散射/护盾/修复/移速/生命/得分/暴击/暴伤/磁吸/回旋护板/虹吸/EMP 强化),永久叠加直至本局结束

## Git 连接排查

若 Git 报 `Recv failure: Connection was reset` 或直连 GitHub 超时，而本机代理可正常访问，请先用 `git -c http.proxy=http://127.0.0.1:<实际端口> ls-remote origin refs/heads/main` 验证代理。确认成功后，可通过 `git config --local remote.origin.proxy http://127.0.0.1:<实际端口>` 仅为当前仓库保存设置。代理必须处于运行状态；恢复直连可执行 `git config --local --unset remote.origin.proxy`。不要关闭 TLS 证书校验。
