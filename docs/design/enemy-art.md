# 敌机轮廓与移动堡垒美术规范

2026-09-24，随 v1.5.0 发布。沿用 Canvas 程序化绘制，无外部位图、字体或下载依赖。

## 轮廓规则

暗色不透明装甲为主体；边缘使用 1.5px 细线及 3px 小范围辉光，保留子弹和攻击预警的优先辨识度。主体尺寸参考已有圆形碰撞半径，外侧小碎片、炮口和连接梁为装饰；未改变碰撞、移动、射击或伤害参数。

| 敌机 | 轮廓与标识 |
|---|---|
| 突击机 | 短箭形，下指尖端 |
| 游弋机 | 宽折翼与内侧 V 线 |
| 俯冲者 | 细矛形、红色尾部能量条 |
| 织网者 | 错位弯翼，非对称转折 |
| 射手机 | 多边形炮座、可见短炮管 |
| 狙击手 | 收窄机身、长炮管与亮色瞄准镜 |
| 重装机 | 宽肩装甲、厚侧块、内层护板 |
| 轰炸机 | 双弹舱、尾部投弹口 |
| 分裂母体 | 两个明确分离的舱体 |
| 镜像机 | 紫色对称双片，不再使用己方青色 |
| 幽灵机 | 偏心主体与悬浮碎片 |
| 护盾支援机 | 青色盾形核心、双翼发生器，不使用十字 |
| 治疗机 | 绿色圆盘与十字，治疗时扩散绿色脉冲 |
| 补给运输机 | 横向货舱、绑带斜线、黄色侧灯 |

护盾保留青色连线与保护环；EMP 禁用时发生器周围出现灰色断环。治疗粒子改为绿色，避免与护盾连线混淆。

## 移动堡垒

- 暗色实体机身、分层肩甲、散热槽与中央能源舱替代高亮空心框。
- 侧面连接梁使用暗色，炮台使用独立装甲底座、炮管、炮口和生命条。
- 蓄力：中心充能条与炮口亮起；预警弹道继续沿用真实攻击数据。
- 装填：两侧舱门打开，显示原有破甲输出窗口；发射后炮台后坐最多 2px、持续 0.18 秒，实际碰撞中心不移动。
- 二阶段：装甲裂纹出现；被摧毁炮台保留断裂底座和微弱余火。
- 所有精灵仍预绘到离屏 Canvas；状态层使用简单几何图形，不新增逐帧大范围阴影。

## 预览与验证

打开 [美术图鉴](../../test/art-lab.html)：14 种普通敌人提供 2× 细节与原始大小并排预览，堡垒提供四种状态；支持灰度、碰撞圆开关。

`node test/art.ui.test.js` 验证所有精灵有可见像素、四种堡垒状态可绘制、绘制不修改战斗状态、移动端无页面横向溢出。截图输出至 `test/artifacts/`。

实战渲染检查覆盖 280×720、390×844、844×390、1280×800；已检查桌面图鉴、碰撞圆与手机实战截图。流派、敌人扩展、输入、792 组 Boss 模式与音乐测试通过。Android / Windows 源资源同步，未重新构建安装包；本次不重新宣称通过数值平衡测试，此前数值报告保留当时源码快照。

## 推广至全 Boss 图鉴

其余 10 种 Boss 采用相同暗色装甲与细边光规范，11 种 Boss 统一经过 `R.drawBoss` 绘制。攻击预警线仍使用真实弹道数据，不根据视觉旋转改变发射方向。

| Boss | 主体与状态特征 |
|---|---|
| 经典首领 | 指挥盾甲、分层肩板、装填时散热口打开 |
| 蜂巢母舰 | 琥珀蜂窝舱，蓄力时逐舱点亮，装填露出舱框 |
| 幻影核心 | 非对称装甲与悬浮碎片，蓄力产生淡残影 |
| 移动堡垒 | 保留独立炮台、开舱、后坐和断裂残骸 |
| 风暴支配者 | 三条机械臂缓慢旋转，二阶段改变视觉旋转方向 |
| 涅槃中枢 | 六块重构装甲围绕核心，装填散热，二阶段开裂 |
| 湮灭漩涡 | 四片弯曲叶片与暗色中心，旋转表现吸入感 |
| 无敌重炮 | 厚重机身与中央长炮管，蓄力能量条和炮口后坐 |
| 超新星 | 八片散热尖瓣、亮核与二阶段径向光线 |
| 双子星环 | 两个不同色核心，按当前攻击轮次强调发射侧 |
| 欧米茄终局 | 分层星形装甲、中心反应堆、二阶段外层能量线与裂纹 |

普通敌人的射击锁定及俯冲蓄力显示暖色亮点；轰炸机强调双弹舱；EMP 眩晕时机身暗化；幽灵相位保留原透明度并增加淡残影；运输机灯带缓慢明暗变化。上述效果只读取已有状态，不新增伤害区域或攻击机制。

图鉴补充每种 Boss 的待机、蓄力、二阶段装填三列，共 33 张 Boss 状态预览，并保留灰度与碰撞圆开关。自动检查全部状态绘制前后战斗对象不变；11 种 Boss 在 280、390、844 宽度实战二阶段运行无页面错误。相关流派、敌机追踪、输入、炮台集成以及 792 组 Boss 模式测试通过。数值报告仍为其对应工作阶段的历史快照。
